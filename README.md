# Eco Sorter – Next Generation Sustainability Platform

A modern, highly animated, premium website for transforming plastic waste into environmental impact. Built with SvelteKit, GSAP animations, and Tailwind CSS.

## 🌟 Features

- 🌍 Full-screen animated hero with particle effects
- 📊 Animated statistics and impact counters
- 🎬 Smooth scroll animations and transitions
- 📱 Fully responsive (desktop, tablet, mobile)
- ♻️ Educational content about plastic pollution
- 🌐 Global impact visualization
- ⚡ Optimized performance with lazy loading
- 💎 Premium glassmorphism design
- 🎨 Light theme with emerald/green color scheme
- 🔐 Role-based authentication system
- 📊 Three separate dashboards (User, Executive, Admin)
- 🚚 Pickup management and tracking
- 💰 Credits and rewards system

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Deployment

The project is configured for static deployment on Netlify.

See [DEPLOYMENT.md](DEPLOYMENT.md) for detailed deployment instructions.

## 🛠️ Tech Stack

- **Framework**: SvelteKit
- **Styling**: Tailwind CSS
- **Animations**: GSAP with ScrollTrigger
- **Icons**: Emoji-based for performance
- **Fonts**: DM Sans Variable
- **Deployment**: Netlify (static)

## 📄 Pages

### Public Pages
- `/` - Homepage with all sections
- `/centers` - Collection Centers directory
- `/contact` - Contact form with glassmorphism
- `/login` - Role-based login page

### Protected Dashboards
- `/dashboard/user` - User dashboard (schedule pickups, track credits)
- `/dashboard/executive` - Executive dashboard (manage pickups, track collections)
- `/dashboard/admin` - Admin dashboard (system monitoring, user management)
